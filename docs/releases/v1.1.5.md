# ClashNL Android v1.1.5

## 修复

- 修复首次从订阅页选择节点后，启动 VPN 时仪表盘节点与实际使用节点不一致的问题。
- 启动时先恢复已保存的节点与代理模式，再更新运行状态，避免界面停留在默认节点。
- 规则模式按核心的默认规则及实际选择链显示节点，避免将未使用的地区或分流组误当作当前节点。

## 安装

普通 Android 手机优先下载 `arm64-v8a.apk`；不确定架构时可下载 `universal.apk`。
其他附件分别用于 `armeabi-v7a`、`x86` 和 `x86_64`。可覆盖安装并保留现有配置。
`SHA256SUMS-1.1.5.txt` 提供全部安装包的 SHA-256 校验值。

规则模式允许不同网站按分流规则使用不同出口；仪表盘当前节点代表默认规则路径。
