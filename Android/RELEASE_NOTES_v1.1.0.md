# ClashNL Android v1.1.0

这是移除账户体系并完成 Mihomo 迁移后的首个基准版本。

## 主要变化

- 彻底移除账户登录、套餐购买、账户同步及相关遗留数据入口。
- Android 运行时迁移为单一原生 Mihomo 核心，避免双 Go runtime 崩溃。
- Clash/Mihomo YAML 订阅原样导入，并在保存、更新和启动前进行原生校验。
- VPN 未启动时也可选择节点、保存节点选择并执行节点延迟测试。
- 规则、全局、直连模式可在启动前预选，也可在运行中切换。
- 仪表盘网络设置支持直接切换“系统代理”和“虚拟网卡”，不再跳转设置页。
- 修复公网 IP 查询绕过 VPN、启动阶段设置竞态、配置监听器安全及 GeoIP 离线加载。
- 系统代理仅发布应用自有的本机 HTTP 监听；订阅无法开启额外监听端口。

## 网络模式说明

- **虚拟网卡**：接管 IPv4、IPv6 与 DNS，推荐用于完整设备代理。
- **系统代理**：要求 Android 10 或更高版本，仅接管遵循 Android 系统 HTTP 代理的应用。

## 验证

- Gradle 格式检查、单元测试和 Release 构建通过。
- Android 真机原生桥接仪器测试 12/12 通过。
- USB 真机验证订阅导入、停机选点、停机测速、模式持久化、系统代理、虚拟网卡及实际出口切换。
