# ClashNL Android v1.1.1

这是以 v1.1.0 为基准的精简维护版本，保持现有功能与界面布局不变。

## 主要变化

- 删除旧 sing-box Android 构建链、补丁覆盖层和过期验证脚本。
- 删除已被 Mihomo 实现替代的配置转换、远程配置和离线测速代码。
- 删除重复的节点组界面、旧仪表盘卡片与无调用组件。
- 清理未使用的导入、参数、成员和历史交接文档。
- 更新 Android 架构说明与第三方组件声明，使其与当前 Mihomo 架构一致。

## 保留功能

- 无账户登录的干净使用流程。
- Clash/Mihomo YAML 订阅导入与更新。
- VPN 未启动时选择节点和执行节点测速。
- 规则、全局、直连代理模式预选与运行中切换。
- 系统代理和虚拟网卡模式直接切换。
- 关于区域仅保留源代码入口。

## 验证

- 代码格式检查、86 项单元测试、Release 关键 Lint 与 R8 构建通过。
- Android 16 arm64 真机仪器测试 12/12 通过。
- USB 真机验证应用启动、节点面板、停机测速入口、代理模式、网络模式和关于页面，无崩溃。
